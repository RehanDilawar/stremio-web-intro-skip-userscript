# ⏩ Stremio Web: Skip Intro (Official Web Port)

[![Greasy Fork](https://img.shields.io/badge/Greasy%20Fork-Install%20Script-red?style=for-the-badge&logo=greasyfork)](https://greasyfork.org/en/scripts/560968-stremio-web-skip-intro-official-web-port)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Supported-green?style=for-the-badge&logo=tampermonkey)](https://www.tampermonkey.net/)
[![Violentmonkey](https://img.shields.io/badge/Violentmonkey-Supported-orange?style=for-the-badge)](https://violentmonkey.github.io/)

A lightweight userscript that ports the **Skip Intro** functionality (originally found in *Stremio Enhanced*) directly to the official Stremio Web application.

---

> [!IMPORTANT]
> **This is a Userscript, not a Stremio Addon.**  
> It only works when accessing Stremio via web browsers at:
> - 🌐 **[web.stremio.com](https://web.stremio.com/)**
> - 🌐 **[web.strem.io](https://web.strem.io/)**

## 🚀 Installation

### Step 1: Install a Userscript Manager
Ensure you have an active userscript manager extension installed in your browser:
* 🐵 **[Tampermonkey](https://www.tampermonkey.net/)** *(Recommended)*
* 🐒 **[Violentmonkey](https://violentmonkey.github.io/)**

### Step 2: Install the Script
Click the link below and select **"Install this script"**:
👉 **[Install from Greasy Fork](https://greasyfork.org/en/scripts/560968-stremio-web-skip-intro-official-web-port)**

### Step 3: Enjoy
Open **[web.stremio.com](https://web.stremio.com/)** or **[web.strem.io](https://web.strem.io/)** and play any supported stream. The skip intro button will automatically appear when intro timestamps are detected.
